# GitGarden 2-Minute Demo Plan

## Demo Script: "Multi-Agent Conversation Orchestration"

### Opening (0:00 - 0:20)
**Presenter**: "Welcome to GitGarden, where conversations become collaborative repositories. Today I'll show you how multiple AI agents can work together to enhance a single development conversation."

**Screen**: GitGarden interface showing empty conversation thread
- **Action**: Create new conversation titled "Authentication System Implementation"
- **Highlight**: Git-like interface with branch/merge capabilities

### Problem Setup (0:20 - 0:40)
**Presenter**: "A developer asks for help implementing user authentication. Instead of a single AI response, GitGarden orchestrates multiple specialized agents."

**Screen**: Show conversation input
- **Action**: Type: "I need to implement a secure user authentication system with JWT tokens"
- **Highlight**: Agent orchestration panel showing 3 agents activating
  - Code Reviewer (Claude 3.5)
  - Test Generator (GPT-4)  
  - Documentation Writer (Claude 3.5)

### Agent Collaboration (0:40 - 1:20)
**Presenter**: "Watch as agents work in parallel, each contributing their expertise to create a comprehensive solution."

**Screen**: Split view showing agent activities
- **0:40-0:50**: Code Reviewer analyzes security vulnerabilities
  - **Action**: Show security issues being flagged (weak password hashing, no rate limiting)
  - **Highlight**: Real-time security score: 6.5/10

- **0:50-1:00**: Test Generator creates comprehensive test suite
  - **Action**: Display generated pytest tests for security scenarios
  - **Highlight**: 87% coverage estimate, 12 test cases generated

- **1:00-1:10**: Documentation Writer produces API reference
  - **Action**: Show auto-generated security guide and integration examples
  - **Highlight**: Multi-format output (Markdown, HTML, PDF)

- **1:10-1:20**: Conversation branching demonstration
  - **Action**: Show "feature/enhanced-auth-security" branch creation
  - **Highlight**: All agent contributions merged into single PR

### Results & Impact (1:20 - 1:50)
**Presenter**: "The result: a production-ready authentication system with security enhancements, comprehensive tests, and complete documentation—all from a single conversation."

**Screen**: Final conversation thread view
- **Action**: Show before/after comparison
  - Before: Basic auth code with security issues
  - After: Enhanced security, bcrypt hashing, rate limiting, full test coverage
- **Highlight**: Conversation commit history showing human + agent contributions

### Closing (1:50 - 2:00)
**Presenter**: "GitGarden transforms conversations into collaborative development workflows, amplifying human creativity with coordinated AI expertise."

**Screen**: Platform overview
- **Action**: Quick scroll through key features
  - Multi-agent orchestration
  - Conversation branching/merging
  - Audit trails and traceability
  - Enterprise security compliance
